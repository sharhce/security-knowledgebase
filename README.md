# Security Knowledge Base

A personal, growing collection of notes, resources, cheat sheets, and references on **AI Security**, **Cloud Security**, **Penetration Testing**, and related topics — built in public so it can help others too.

> Status: 🌱 Just getting started. Structure is in place; content is being added over time.

## Contents

| Folder | What's in it |
|---|---|
| [`ai-security/`](./ai-security) | LLM/AI system security — prompt injection, model risks, AI red teaming, secure AI deployment |
| [`cloud-security/`](./cloud-security) | AWS / Azure / GCP hardening, IAM, cloud misconfigurations, cloud-native threats |
| [`penetration-testing/`](./penetration-testing) | Methodologies, recon, exploitation notes, reporting templates |
| [`web-security/`](./web-security) | OWASP Top 10, web app testing techniques, common vulnerabilities |
| [`network-security/`](./network-security) | Network protocols, segmentation, monitoring, common attack techniques |
| [`tools-and-resources/`](./tools-and-resources) | Useful tools, learning platforms, blogs, and general references |

Each folder has its own `README.md` with an overview and links; sub-pages/notes will be added inside them as the collection grows.

## Why this repo exists

This is a working knowledge base — a place to collect and organize what I'm learning about security, and to share it with anyone else who finds it useful. Expect it to change shape as it grows.
