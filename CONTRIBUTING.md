# Contributing

Thanks for considering a contribution to this knowledge base!

## Ways to contribute

- **Fix an error** — typo, broken link, outdated info: open a pull request or an issue.
- **Add a resource** — a genuinely useful article, tool, or cheat sheet for one of the existing topics.
- **Suggest a new topic/folder** — open an issue describing what's missing and why it fits.

## Guidelines

- Keep entries factual and cite sources where relevant.
- Prefer original notes/summaries over copy-pasting large chunks of other people's writing.
- Educational/defensive framing only — see the disclaimer in the main [README](./README.md).
- Use clear Markdown headings so new sections are easy to scan.

## How to submit changes

1. Fork the repository.
2. Create a branch for your change.
3. Make your edits.
4. Open a pull request describing what you changed and why.

Not comfortable with git/GitHub yet? You can also just open an **Issue** describing the suggested addition or correction, and it can be added directly.
